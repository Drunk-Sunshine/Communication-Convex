# 优化算法分类总结  

优化算法可以根据问题的性质和需求进行分类。以下是一些常见的优化算法及其适用的问题类型：  

## 1. 线性规划（Linear Programming）  

- **算法**：  
  - **单纯形法（Simplex Method）**：用于求解线性规划问题，适用于线性目标函数和线性约束。  
  - **内点法（Interior Point Method）**：用于求解大规模线性规划问题，具有良好的数值稳定性。  

- **适用问题**：  
  - 线性目标函数和线性约束条件的问题。  

## 2. 非线性规划（Nonlinear Programming）  

- **算法**：  
  - **梯度下降法（Gradient Descent）**：用于无约束优化问题，适合连续可微的目标函数。  
  - **牛顿法（Newton's Method）**：用于无约束优化，适合二阶可微的目标函数。  
  - **共轭梯度法（Conjugate Gradient Method）**：用于大规模无约束优化问题。  
  - **拉格朗日乘子法（Lagrange Multipliers）**：用于有约束优化问题。  

- **适用问题**：  
  - 非线性目标函数，可能有非线性约束。  

## 3. 整数规划（Integer Programming）  

- **算法**：  
  - **分支定界法（Branch and Bound）**：用于求解整数规划问题。  
  - **割平面法（Cutting Plane Method）**：用于求解混合整数规划问题。  

- **适用问题**：  
  - 需要整数解的优化问题。  

## 4. 动态规划（Dynamic Programming）  

- **算法**：  
  - **贝尔曼方程（Bellman Equation）**：用于分阶段决策问题。  
  - **记忆化搜索（Memoization）**：用于优化递归问题。  

- **适用问题**：  
  - 具有重叠子问题和最优子结构性质的问题。  

## 5. 随机优化（Stochastic Optimization）  

- **算法**：  
  - **模拟退火（Simulated Annealing）**：用于全局优化问题，适合非凸问题。  
  - **遗传算法（Genetic Algorithm）**：用于全局优化问题，适合复杂搜索空间。  
  - **粒子群优化（Particle Swarm Optimization）**：用于全局优化问题，适合连续和离散问题。  

- **适用问题**：  
  - 复杂的非凸问题，具有多个局部最优解。  

## 6. 凸优化（Convex Optimization）  

- **算法**：  
  - **次梯度法（Subgradient Method）**：用于非光滑凸优化问题。  
  - **交替方向乘子法（ADMM）**：用于分布式优化问题。  

- **适用问题**：  
  - 凸目标函数和凸约束条件的问题。  

## 7. 强化学习中的优化  

- **算法**：  
  - **Q-learning**：用于离散动作空间的强化学习问题。  
  - **策略梯度法（Policy Gradient Methods）**：用于连续动作空间的强化学习问题。  

- **适用问题**：  
  - 需要通过试错学习策略的动态环境。  

这些算法各有其适用的场景和问题类型，选择合适的优化算法需要根据具体问题的性质、规模和约束条件来决定。



# CVX 支持的优化求解器  

| 求解器 | 用途                                                         | 特点                                                         |
| ------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| SDPT3  | 半定规划（SDP）和相关的凸优化问题                            | 基于内点法，适合处理大型稀疏问题；在高维半定规划问题中表现良好。 |
| SeDuMi | 线性规划（LP）、二次规划（QP）和半定规划（SDP）              | 基于内点法，能够高效处理稀疏矩阵；支持多种形式的约束。       |
| Gurobi | 线性规划（LP）、整数规划（IP）和混合整数规划（MIP）          | 高效的求解器，适合大规模优化问题；提供并行计算和灵活建模接口。 |
| CPLEX  | 线性规划（LP）、整数规划（IP）和混合整数规划（MIP）          | IBM 提供的强大求解器，适合复杂优化问题；提供多种求解策略。   |
| MOSEK  | 线性规划（LP）、二次规划（QP）、半定规划（SDP）和混合整数规划（MIP） | 高效的求解器，特别适合大规模问题；提供灵活的建模接口。       |
| OSQP   | 二次规划（QP）                                               | 适合处理稀疏问题，特别在实时应用中表现良好；基于交替方向乘子法。 |
| SCS    | 线性规划（LP）、二次规划（QP）和其他凸优化问题               | 基于分裂坐标下降法，适合处理大规模问题；适合内存受限环境。   |

CVX支持四种求解器：SeDuMi、SDPT3、Gurobi和MOSEK，其中SeDuMi和SDPT3内置，Gurobi和MOSEK需专业许可证。默认求解器为SDPT3，SeDuMi速度较快但可能不稳定。用户可使用cvx_solver命令切换求解器。控制屏幕输出和精度调整有助于优化使用体验。对于高级设置，cvx_solver_settings允许用户自定义求解器参数，但需谨慎操作。
